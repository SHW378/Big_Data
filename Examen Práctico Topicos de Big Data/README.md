# Examen práctico — Primer parcial

Análisis del porcentaje de adultos de 15 años o más que bebieron alcohol durante el
último año. Los datos provienen de Our World in Data.

**Alumno:** César Alberto Cázares Chaván  
**Matrícula:** 82196  
**Dataset asignado:** alcohol

## Contenido

- `notebooks/plantilla_examen_parcial1.ipynb`: examen completo con código,
  resultados, gráficas e interpretaciones.
- `src/01_pipeline_alcohol.py`: descarga y prepara una copia reproducible del dataset.
- `data/raw/alcohol/`: datos y metadatos originales.
- `data/processed/`: ranking de países correspondiente a 2020.

El dataset abarca de 2000 a 2020. En la pregunta que solicita 2023 se utiliza 2020,
porque es el año disponible más cercano.
